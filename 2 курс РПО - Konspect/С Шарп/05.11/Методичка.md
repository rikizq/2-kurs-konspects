### 1. Основные понятия ООП

Объектно-ориентированное программирование (ООП) - подход к программированию, при котором реальные сущности представляются в виде объектов. Каждый объект имеет характеристики (данные) и поведение (функции).

Например, автомобиль имеет цвет, марку, год выпуска и скорость, а также может заводиться, разгоняться и тормозить.

Основные понятия:

- Класс - шаблон, по которому создаются объекты.
- Объект - конкретный экземпляр класса.
- Свойства (атрибуты) - характеристики объекта.
- Методы - действия, которые может выполнять объект.

### 2. Четыре принципа ООП

1. Абстракция

Выделение главных характеристик объекта и игнорирование второстепенных деталей. Позволяет представить сложную систему в упрощённом виде.

Пример: водитель использует руль и педали автомобиля, не разбираясь в устройстве двигателя.

Суть: Вы определяете, что объект делает, скрывая как он это делает

2. Инкапсуляция

Объединение данных и методов внутри объекта и защита внутреннего состояния от прямого доступа извне. Для взаимодействия с объектом используются специальные методы и свойства.

Пример: управление смартфоном осуществляется через экран и кнопки, а не через прямое изменение внутренних компонентов.

Суть: Объединение данных и методов, работающих с ними, в одном объекте и защита данных от некорректного внешнего использования

3. Наследование

Механизм создания нового класса на основе существующего. Производный класс получает доступные поля и методы базового класса и может дополнять или переопределять их.

Пример: класс «Автомобиль» наследует общие свойства класса «Транспорт», но добавляет собственные действия.

Суть: Возможность описывать новый класс на основе уже существующего, переиспользуя код и выстраивая иерархии

4. Полиморфизм

Возможность использовать объекты разных классов через общий интерфейс или базовый класс, при этом каждый объект может выполнять действие по-своему.

Пример: метод `ИздатьЗвук()` для собаки выводит «Гав», для кошки - «Мяу», для коровы - «Му».

Суть: один интерфейс - множество реализаций.

### 3. Перегрузка методов

Перегрузка методов - возможность объявлять в одном классе несколько методов с одинаковым именем, но разными параметрами. Параметры могут отличаться типом, количеством или порядком.

Пример:

```
public class Calculator
{
    public int Add(int a, int b)
    {
        return a + b;
    }

    public int Add(int a, int b, int c)
    {
        return a + b + c;
    }

    public double Add(double a, double b)
    {
        return a + b;
    }

    public string Add(string a, string b)
    {
        return a + b;
    }
}
```

Перегрузка бывает:

- По типу параметров - например, `int`, `string`, `double`.
- По количеству параметров - метод может принимать один, два или три аргумента.
- По порядку параметров - меняется последовательность типов параметров.


Преимущества перегрузки:

- Удобство использования методов.
- Гибкость при передаче аргументов.
- Возможность добавлять новые варианты методов.
- Улучшение читаемости кода.


### 4. Классы и объекты

Класс - логическая модель, которая описывает будущий объект. В нём определяются поля и методы.

Для объявления класса используется ключевое слово `class`.

Пример:

```
class Person
{
    public string name = "";
    public int age;
    public string male = "";

    public void SayHello()
    {
        Console.WriteLine($"Привет, меня зовут {name}");
    }
}
```

В классе Person:

- `name`, `age`, `male` - поля;
- `SayHello()` - метод.

### Модификаторы доступа

Модификаторы определяют, откуда можно обращаться к членам класса.

- `public` - доступен всем.
- `protected` - доступен внутри класса и его потомкам.
- `private` - доступен только внутри самого класса.
- `internal` - доступен в пределах текущей сборки.

### Создание объектов

Для создания объекта используется оператор `new`.

```
Person person = new Person();

person.name = "Test";
person.age = 5;
person.male = "м";
```

Также можно использовать инициализатор:

```
Person person = new Person()
{
    name = "Test",
    age = 5,
    male = "м"
};
```

Класс является описанием объекта, а сам объект создаётся в памяти при помощи `new`.

### 5. Создание и удаление объектов. Сборщик мусора

В C# память для объектов классов выделяется динамически.

Когда объект больше не используется и на него не существует доступных ссылок, его память может быть освобождена.

Сборщик мусора (Garbage Collector) - специальная система, которая автоматически управляет освобождением памяти.

Основные функции:

1. Обнаружение недоступных объектов.
2. Освобождение памяти, которую они занимают.

В отличие от C++, где программист может самостоятельно освобождать память оператором `delete`, в C# этим занимается сборщик мусора.

### 6. Свойства класса

Свойства позволяют получать и изменять значения закрытых полей класса, контролируя доступ к ним.

Свойство состоит из двух аксессоров:

- `get` - чтение значения;
- `set` - запись нового значения.

Внутри `set` используется ключевое слово `value`, которое содержит передаваемое значение.

Пример:

```
class Person
{
    private string name;

    public string Name
    {
        get { return name; }
        set { name = value; }
    }
}
```

Свойства позволяют:

- Ограничивать изменение данных.
- Проверять правильность вводимых значений.
- Разрешать только чтение или только запись.
- Защищать внутренние поля класса.

Если свойство содержит только `get`, значение можно читать, но нельзя изменять через это свойство. Если содержит только `set`, значение можно записывать, но нельзя читать.

Обычно поля именуются со строчной буквы, а свойства - с прописной.

### 7. Конструкторы

Конструктор - специальный метод, который инициализирует объект при его создании.

Он используется для присвоения начальных значений полям и выполнения дополнительных действий.

Особенности конструктора:

- Имя совпадает с именем класса.
- Не возвращает значение.
- Тип возвращаемого значения не указывается.
- Вызывается при создании объекта.
- Может принимать параметры или не принимать их.

Пример:

```
class Person
{
    public string name;
    public int age;
    public string male;

    public Person(string name, int age, string male)
    {
        this.name = name;
        this.age = age;
        this.male = male;
    }
}
```

Создание объекта:

```
Person person = new Person("Test", 5, "м");
```

Ключевое слово `this` обозначает текущий объект. Оно позволяет различать поля класса и параметры конструктора с одинаковыми именами.

Конструкторы удобнее обычных инициализирующих методов, потому что выполняют настройку объекта сразу при создании.

### 8. Статические поля и методы

Ключевое слово `static` обозначает, что поле или метод принадлежит классу, а не отдельному объекту.

Статические методы можно вызывать без создания экземпляра класса.

Особенности:

- Статическое поле является общим для всех объектов класса.
- Статический метод может напрямую обращаться к статическим членам класса.
- Статический метод не может напрямую обращаться к нестатическим полям конкретного объекта.
- Для обращения к нестатическим членам требуется экземпляр объекта.

Пример:

```
class Person
{
    static int ObjectNumber = 0;

    public Person()
    {
        ObjectNumber++;
    }

    public int GetObjectNumber()
    {
        return ObjectNumber;
    }
}
```

Каждый раз при создании объекта счётчик увеличивается. Все экземпляры используют одно общее статическое поле.

### 9. Массивы объектов

Для хранения нескольких объектов одного класса можно использовать массив.

Массив создаётся с помощью оператора `new`, а его размер задаётся заранее.

Пример:

```
Person[] person = new Person[2];

for (int i = 0; i < person.Length; i++)
{
    person[i] = new Person("Иван", 20, "м");
}
```

Массив хранит ссылки на объекты. Поэтому после создания массива необходимо отдельно создать каждый объект и поместить его в соответствующий элемент.

Недостаток массива: размер фиксирован и не может автоматически изменяться при добавлении новых элементов.

### 10. Списки объектов

Для хранения объектов с изменяемым количеством элементов используются динамические списки `List<T>`.

Пример:

```
List<Person> Persons = new List<Person>();

Persons.Add(new Person("Данил", 5, "Мальчик"));
Persons.Add(new Person("Иван", 20, "М"));

foreach (Person person in Persons)
{
    person.info();
}
```

Основные методы списка:

- `Add()` - добавляет элемент.
- `Remove()` - удаляет элемент по ссылке на объект.
- `RemoveAt()` - удаляет элемент по индексу.
- `Insert()` - вставляет элемент по указанному индексу.

Главное отличие: массив имеет фиксированный размер, а список позволяет добавлять и удалять элементы во время работы программы.

### 11. Перегрузка операторов

Перегрузка операторов - возможность определять собственное поведение стандартных операторов для объектов пользовательских классов.

Например, можно определить сложение двух объектов с помощью оператора `+`.

Для этого используется ключевое слово `operator`.

Пример:

```
class MyPoint
{
    public int X { get; set; }
    public int Y { get; set; }

    public MyPoint(int x, int y)
    {
        X = x;
        Y = y;
    }

    public static MyPoint operator +(MyPoint a, MyPoint b)
    {
        return new MyPoint(a.X + b.X, a.Y + b.Y);
    }
}
```

Использование:

```
MyPoint p1 = new MyPoint(10, 20);
MyPoint p2 = new MyPoint(20, 10);

MyPoint p3 = p1 + p2;

Console.WriteLine(p3.X); // 30
```

Таким образом, оператор `+` выполняет сложение соответствующих координат двух объектов.

Также можно перегружать операторы сравнения, например `>` и `<`.

### 12. Операторы приведения типов

Преобразование типов позволяет преобразовать объект одного типа в другой.

В C# существуют два основных вида пользовательского преобразования.

Явное преобразование (`explicit`)

Требует указания целевого типа в месте преобразования.

Пример:

```
public static explicit operator MyPoint(Person person)
{
    return new MyPoint(person.X, person.Y);
}
```

Использование:

```
MyPoint p2 = (MyPoint)person;
```

Преобразование явно указывается в круглых скобках.

Неявное преобразование (`implicit`)

Выполняется автоматически, без указания типа в месте вызова.

Пример:

```
public static implicit operator MyPoint(Person person)
{
    return new MyPoint(person.X, person.Y);
}
```

Использование:

```
MyPoint p2 = person;
```

Разница:

- `explicit` - преобразование необходимо указывать вручную.
- `implicit` - преобразование выполняется автоматически.
