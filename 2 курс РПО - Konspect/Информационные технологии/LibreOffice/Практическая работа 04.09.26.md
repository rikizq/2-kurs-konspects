### Работа со списками

Маркированный список

- Выделить текст.
- Нажать кнопку «Маркеры» на панели инструментов
- Для создания нового пункта нажимать Enter
- Для завершения списка нажать Enter два раза

Нумерованный список

1. Выделить текст
2. Нажать кнопку «Нумерация»
3. При нажатии Enter автоматически создаётся следующий пункт

Автоматические списки

LibreOffice Writer автоматически распознаёт начало списка, например `1.` или `-`, и преобразует его в список

Форматирование списков

Можно изменить вид маркеров и нумерации, отступы, положение номера и уровень вложенности через Формат - Списки

### Работа со стилями

Стиль - это набор настроек форматирования текста. Стили позволяют быстро применять одинаковое оформление к разным частям документа.

Панель стилей открывается клавишей F11.

Для заголовков удобно использовать:

- Заголовок 1
- Заголовок 2
- Заголовок 3
- Основной текст

Создание стиля

Открыть F11 - Стили абзаца - Создать.  
Задать название стиля и настроить шрифт, размер, интервалы, отступы и другие параметры. После этого нажать ОК и применить стиль к тексту

### Проверка орфографии и грамматики

Для проверки документа используется Сервис - Орфография или клавиша F7.

Ошибки обычно подчёркиваются красной волнистой линией. Можно щёлкнуть по слову правой кнопкой мыши и выбрать правильный вариант

### Смена языка

Язык текста можно изменить через Сервис - Язык или выбрать язык в строке состояния в нижней части окна.

### Расстановка переносов

Для расстановки переносов используется Сервис - Язык - Расстановка переносов.

Переносы помогают правильно распределять слова по строкам

### Поиск и замена текста

Ctrl + F - поиск текста.

Ctrl + H - поиск и замена.

В окне можно указать, какой текст найти и на какой текст его заменить. Также можно использовать функцию «Заменить всё»

### Вставка специальных символов

Выбрать Вставка - Специальный символ.

Можно вставить символы, которых нет на клавиатуре, например:

€, ¥, £, ©, Σ, Ω

### Управление просмотром документа

Масштаб документа можно изменить через Вид - Масштаб или с помощью ползунка в нижней части окна

Для удобной работы с большим документом используется **Навигатор**, который открывается клавишей F5

### Просмотр и перемещение внутри документа

Для перемещения по документу используются:

- Ctrl + Home - начало документа
- Ctrl + End - конец документа
- Home - начало строки
- End - конец строки
- Page Up / Page Down - перемещение вверх и вниз
- F5 - Навигатор

### Переход по закладке

Закладка позволяет отметить определённое место документа

Для создания закладки: Вставка - Закладка

После задания имени закладки можно быстро перейти к ней через Навигатор (F5)

### Использование гиперссылок

Гиперссылка позволяет перейти на веб-страницу, файл или другое место документа.

Выделить текст - нажать Ctrl + K - указать адрес - нажать Применить

### Оформление документа

Документ рекомендуется оформлять в едином стиле.

Обычно структура учебной работы выглядит так:

Титульный лист - Содержание - Введение - Основная часть - Заключение - Список литературы.

### Создание титульного листа

На титульном листе обычно указывают:

- название учебного заведения
- название предмета
- тему работы
- вид работы
- ФИО студента
- ФИО преподавателя
- Дата Сдачи

После титульного листа можно вставить разрыв страницы с помощью Ctrl + Enter.

### Создание списка литературы

В конце документа создаётся раздел «Список литературы»

Для работы с библиографией в LibreOffice можно использовать Сервис - База данных библиографии

Источники записываются по порядку:

1. Автор. Название книги. - Город, год
2. Автор. Название статьи. - Год
3. Название сайта или ссылка на источник.

Можно просто написать список источников вручную и оформить его нумерованным списком.
