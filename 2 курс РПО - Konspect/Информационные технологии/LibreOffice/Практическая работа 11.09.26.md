### Практическая работа №9
### Работа с рисунками в документе

В LibreOffice Writer можно добавлять в документ рисунки, фотографии, схемы и другие изображения. После вставки рисунок можно перемещать по странице, изменять его размер, поворачивать и настраивать его расположение относительно текста. Изображение можно использовать как часть оформления или как иллюстрацию к тексту.

### Вставка рисунков

Для добавления изображения используется Вставка - Изображение. Также рисунок можно скопировать и вставить в документ. После добавления можно изменить его ширину и высоту, положение на странице и границы. Размер удобнее менять за угловые маркеры, чтобы сохранить пропорции рисунка.

### Составление блок-схемы

Блок-схема используется для изображения последовательности действий или алгоритма. Она создаётся с помощью фигур и соединительных линий. Для разных действий используются разные фигуры: прямоугольник показывает действие, ромб - условие, овал - начало или конец, а стрелки показывают направление выполнения.

### Переупорядочивание слоёв рисунка и вращение фигур

Если несколько объектов расположены друг на друге, можно изменить их порядок. Фигуру можно переместить на передний или задний план, а также поднять или опустить на один уровень. Это помогает правильно расположить объекты на странице. Фигуры также можно вращать с помощью инструмента поворота.

### Создание рисунка-подложки для текста

Изображение можно использовать как подложку для текста. Для этого рисунок размещают за текстом и настраивают его положение. Такой способ подходит для оформления страниц, фона или размещения текста поверх изображения.

### Управление обтеканием рисунка текстом

Обтекание определяет, как текст будет располагаться рядом с изображением. Можно выбрать расположение текста вокруг рисунка, отдельно от него, перед рисунком или за ним. Настройка обтекания помогает правильно разместить изображение внутри документа.

### Работа с научными формулами

Для создания математических и научных формул в LibreOffice Writer используется редактор формул. С его помощью можно создавать дроби, степени, корни, индексы, интегралы и другие выражения. Формула добавляется через Вставка - Объект - Формула. После вставки её можно редактировать и изменять отдельные элементы.

# Глава 2. Табличный процессор (LibreOffice Calc)

### Табличный процессор

LibreOffice Calc предназначен для создания и обработки электронных таблиц. В нём можно вводить данные, выполнять расчёты, использовать формулы и функции, а также создавать диаграммы. Таблица состоит из строк, столбцов и ячеек. Каждая ячейка имеет свой адрес, например **A1** или **B5**.

### Создание книг

В Calc можно создавать электронные книги, которые содержат несколько листов. Листы можно добавлять, удалять, переименовывать и менять их порядок. На разных листах можно хранить разные данные.

Новая книга создаётся через Файл - Создать - Электронная таблица.

### Форматирование таблиц

Для удобной работы с таблицей можно изменять её внешний вид. Настраиваются шрифт и размер текста, выравнивание, границы ячеек, ширина столбцов и высота строк. Также можно изменять формат чисел, дат, процентов и других значений.

### Специальные возможности Calc

Calc позволяет сортировать и фильтровать данные, использовать условное форматирование и создавать диаграммы. Сортировка помогает расположить данные в нужном порядке. Фильтр позволяет оставить только строки, которые соответствуют выбранным условиям. Условное форматирование изменяет вид ячеек в зависимости от их значения.

### Формулы

Формулы используются для выполнения расчётов и начинаются со знака **=**. В них можно использовать числа, адреса ячеек, математические операторы и функции.

Основные операторы:

- **+** - сложение

- **-** - вычитание

- * - умножение

- **/** - деление

- **^** - степень


В LibreOffice Calc есть готовые функции, которые помогают выполнять расчёты с данными в таблице.

- **СУММ()** - складывает числа из выбранных ячеек. Например: `=СУММ(A1:A5)`
- **СРЗНАЧ()** - вычисляет среднее значение чисел. Например: `=СРЗНАЧ(B1:B5)`
- **ЕСЛИ()** - проверяет условие и выводит один из двух результатов. Например: `=ЕСЛИ(A1>10;"Да";"Нет")`
- **МАКС()** - находит самое большое значение в выбранном диапазоне. Например: `=МАКС(A1:A10)`
- **МИН()** - находит самое маленькое значение. Например: `=МИН(A1:A10)`
- **СЧЁТ()** - считает количество ячеек, в которых находятся числа. Например: `=СЧЁТ(A1:A10)`

### Макросы

Макросы используются для автоматизации повторяющихся действий. Они позволяют выполнить несколько операций автоматически и могут работать с данными таблицы.

Для создания макросов используется LibreOffice Basic. С помощью макросов можно изменять оформление ячеек, заполнять таблицы и выполнять другие действия.

Макросы открываются через Сервис - Макросы. Формулы в основном используются для расчётов, а макросы - для автоматизации действий.
