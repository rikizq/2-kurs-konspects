### Перемещение указателя ячейки (активной ячейки)

Активная ячейка - это ячейка, в которую в данный момент можно вводить или редактировать данные.

Для перемещения по таблице используются:

- Стрелки на клавиатуре - переход к соседним ячейкам.
- Enter - переход к следующей ячейке вниз.
- Tab - переход к следующей ячейке вправо.
- Ctrl + Home - переход к началу листа.
- Щелчок мышью - переход к нужной ячейке.
### Выделение различных диапазонов

Диапазон - это одна или несколько ячеек таблицы.

**Выделение смежного диапазона**

- Щёлкнуть по первой ячейке.
- Зажать левую кнопку мыши и протянуть указатель до последней ячейки.
- Также можно выделить первую ячейку, зажать Shift и щёлкнуть по последней.

**Выделение несмежного диапазона**

- Выделить первый диапазон.
- Зажать Ctrl.
- Выделить мышью другие ячейки или диапазоны.

### Ввод и редактирование данных

Для ввода данных необходимо:

- Выбрать нужную ячейку.
- Ввести текст, число или дату с клавиатуры.
- Нажать Enter для подтверждения ввода.

Для редактирования данных можно дважды щёлкнуть по ячейке или выбрать её и нажать F2. Также можно изменить содержимое в строке ввода формул.

Для удаления содержимого ячейки следует выделить её и нажать Delete.

### Установка ширины столбцов

Ширина столбца определяет, сколько места отводится для отображения данных.

Для изменения ширины столбца:

- Навести указатель мыши на границу между буквенными заголовками столбцов.
- Зажать левую кнопку мыши и перетащить границу в нужную сторону.
- Для автоматической подгонки ширины дважды щёлкнуть по границе столбца.

Также можно выбрать Формат - Столбцы - Ширина и указать нужное значение.

### Использование автозаполнения

Автозаполнение позволяет быстро копировать данные или продолжать последовательности.

Для этого необходимо:

- Ввести данные в одну или несколько ячеек.
- Выделить заполненные ячейки.
- Навести указатель на маленький маркер в правом нижнем углу выделения.
- Зажать левую кнопку мыши и протянуть маркер на нужное количество ячеек.

При вводе чисел 1 и 2 в соседние ячейки можно продолжить последовательность: 3, 4, 5, 6.

### Ввод формул для ячеек смежного и несмежного диапазона

Формулы используются для выполнения вычислений в таблице. Любая формула начинается со знака `=`.

Примеры формул:

- `=A1+B1` - сложение значений.
- `=A1-B1` - вычитание.
- `=A1*B1` - умножение.
- `=A1/B1` - деление.
- `=SUM(A1:A5)` - сумма значений диапазона.

В русскоязычной версии программы имя функции может отображаться как `СУММ`.

**Для смежного диапазона:**

- Выбрать нужную ячейку.
- Ввести формулу, например `=SUM(A1:A5)`.
- Нажать Enter.

**Для несмежных ячеек:**

Можно указать отдельные ячейки в одной формуле, например `=A1+B1+D1`, чтобы сложить их значения.

### Копирование формул на смежные и несмежные ячейки

**Копирование на смежные ячейки**

- Ввести формулу в первую ячейку.
- Выделить ячейку с формулой.
- Перетащить маркер автозаполнения на соседние ячейки.

При копировании формулы относительные ссылки обычно изменяются автоматически. Например, формула `=A1+B1` при копировании на строку ниже станет `=A2+B2`.

**Копирование на несмежные ячейки**

- Выделить ячейку с формулой.
- Нажать Ctrl + C.
- С зажатой клавишей Ctrl выделить нужные несмежные ячейки.
- Нажать Ctrl + V.

При копировании формул следует учитывать относительные и абсолютные ссылки. Для закрепления ссылки используется знак `$`, например `$A$1`.
