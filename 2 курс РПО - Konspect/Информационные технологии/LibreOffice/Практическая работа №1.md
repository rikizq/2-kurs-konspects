LibreOffice Writer - текстовый процессор, входящий в состав пакета LibreOffice. Он используется для создания, редактирования, форматирования, сохранения и печати текстовых документов.
![[Pasted image 20260903132227.png]]
### Структура экрана

Основными элементами окна LibreOffice являются строка заголовка, строка меню, панели инструментов, рабочая область, линейки, полосы прокрутки и строка состояния. В строке меню находятся команды «Файл», «Правка», «Вид», «Вставка», «Формат», «Стили», «Таблица», «Форма», «Сервис», «Окно» и «Справка».
![[Pasted image 20260903132121.png]]
Панели инструментов содержат кнопки основных команд. Рабочая область используется для ввода и редактирования текста. Линейка нужна для настройки отступов и табуляции. В строке состояния отображаются номер страницы, количество слов, язык и масштаб.
![[Pasted image 20260903134352.png]]
### Создание и сохранение документа

Для создания нового документа нужно открыть меню «Файл», выбрать «Создать», затем «Текстовый документ». Быстрее использовать сочетание Ctrl+N.
![[Pasted image 20260903134135.png]]
Для сохранения используется «Файл», «Сохранить» или Ctrl+S. При первом сохранении нужно указать имя файла, папку и формат. Основной формат LibreOffice Writer - ODF. Также документ можно сохранить в форматах DOCX и PDF. Я всегда использую PDF.
![[Pasted image 20260903134512.png]]
### Создание и форматирование документа

После создания документа можно вводить и редактировать текст. Текст можно удалять, копировать, перемещать и изменять. При форматировании изменяется его внешний вид.

Основные параметры форматирования: шрифт, размер, цвет, полужирное начертание, курсив, подчёркивание, выравнивание, отступы и интервалы.
![[Pasted image 20260903134856.png]]
Чтобы изменить отдельный фрагмент текста, его сначала нужно выделить

### Разметка страницы

В настройках страницы можно изменить размер бумаги, поля и ориентацию. Ориентация бывает книжной и альбомной. Для изменения параметров нужно открыть меню «Формат» и выбрать «Стиль страницы».
![[Pasted image 20260903133503.png]]
### Списки и таблицы

В Writer можно создавать маркированные и нумерованные списки. Маркированный список используется для обычного перечисления, нумерованный - когда важен порядок пунктов.

Таблица состоит из строк и столбцов. В ней можно добавлять и удалять строки и столбцы, объединять ячейки, изменять их размер, границы и заливку
![[Pasted image 20260903134953.png]]
### Шрифты

Шрифт определяет вид текста. В Writer можно менять название, размер, цвет и начертание шрифта. Доступны полужирный, курсив и подчёркивание. Для изменения шрифта нужно выделить текст и выбрать нужные параметры на панели инструментов
![[Pasted image 20260903134803.png]]
### Специальные возможности

В Writer есть проверка орфографии, поиск и замена текста, автоматическое создание списков, стили, комментарии и примечания. Можно вставлять специальные символы, изображения, таблицы и другие объекты
![[Pasted image 20260903135342.png]]
### Практическая работа №2. Редактирование документа

### Выделение блоков текста

Текст можно выделять мышью или клавиатурой. Можно выделить слово, предложение, строку, абзац или несколько абзацев. Для выделения всего документа используется Ctrl+A

### Операции с выделенным текстом

- Ctrl+C - копировать
- Ctrl+X - вырезать
- Ctrl+V - вставить
- Delete - удалить
- Ctrl+Z - отменить действие
- Ctrl+Y - повторить действие
### Контекстное меню

Контекстное меню открывается правой кнопкой мыши. В нём находятся команды для работы с выделенным текстом и объектами. Через него можно копировать, вырезать, вставлять, удалять и форматировать текст
![[Pasted image 20260903135648.png]]
### Масштабирование рабочего окна

Масштаб изменяет размер документа на экране. На размер текста при печати он не влияет. Изменить масштаб можно в нижней части окна
![[Pasted image 20260903135948.png]]
### Форматирование абзацев

Для абзаца можно установить выравнивание по левому краю, по центру, по правому краю или по ширине. Также можно изменить левый и правый отступы, отступ первой строки, межстрочный интервал и расстояние между абзацами

### Работа с линейкой

Линейка используется для настройки отступов и табуляции. С её помощью можно изменить положение первой строки, левого и правого отступов и выступа
![[Pasted image 20260903135858.png]]
### Режим предварительного просмотра

Предварительный просмотр нужен для проверки документа перед печатью. В нём можно проверить расположение текста, таблиц и изображений, поля и разрывы страниц

Для открытия предварительного просмотра нужно открыть меню «Файл» и выбрать «Просмотр печати»

### Практическая работа №3

### Маркированные списки

Маркированный список используется для перечисления пунктов, порядок которых не важен.

• Текстовый процессор  
• Графический редактор  
• Табличный процессор

### Нумерованные списки

Нумерованный список используется, когда пункты имеют определённый порядок.

1. Создать документ.
2. Ввести текст.
3. Отформатировать текст.
4. Сохранить документ.

### Автоматические списки

Writer может автоматически создавать списки. Если начать строку с номера и точки или специального символа, программа распознаёт список. После нажатия Enter следующий пункт получает новый номер или маркер.

### Форматирование списков

Для списка можно изменить маркер, нумерацию, отступы и положение текста. Также можно создавать многоуровневые списки.
![[Pasted image 20260903140551.png]]
### Работа со стилями

Стиль - это набор настроек форматирования текста. Стили позволяют быстро применять одинаковое оформление к разным частям документа.

В Writer есть стили абзацев, символов, страниц и списков. Для заголовков используются стили «Заголовок 1», «Заголовок 2» и другие.

### Создание стиля

Для создания стиля нужно открыть панель «Стили» с помощью **F11**, выбрать нужный тип стиля и создать новый. Затем задаются название, шрифт, размер, цвет, отступы и интервалы. После сохранения стиль можно применять к тексту.
