**ORDER BY** - сортирует итоговый набор строк по одному или нескольким столбцам.
- По умолчанию сортирует по возрастанию (**ASC**), для обратного порядка используется DESC.
- Пишется в самом конце запроса — уже после FROM, WHERE, GROUP BY и HAVING
- Можно сортировать по нескольким полям сразу (например, сначала по категории, потом по цене) и по псевдонимам из SELECT.
