## 1. Связь один к одному (1:1)

1. **Человек - паспорт**
   У одного человека может быть один действующий паспорт, и этот паспорт принадлежит только одному человеку. 

2. **Студент - студенческий билет**
   Один студент имеет один студенческий билет, и один билет принадлежит только одному студенту. Поэтому это связь **1:1**, а не 1:N.

3. **Сотрудник - рабочее место**
   За одним сотрудником закреплено одно рабочее место, и это место закреплено только за одним сотрудником. Поэтому связь **1:1**.

4. **Компьютер - инвентарный номер**
   За одним компьютером закрепляется один инвентарный номер. Один номер нельзя одновременно присвоить нескольким компьютерам. Значит, связь **1:1**.

## 2. Связь один ко многим (1:N)

1. **Преподаватель - группы**
   Один преподаватель может вести несколько групп, но одна группа по конкретному предмету имеет одного преподавателя. Поэтому здесь **1:N**, а не 1:1.

2. **Магазин - товары**
   В одном магазине хранится много товаров. При этом каждый конкретный товар из этой таблицы относится к одному магазину. Значит, связь **1:N**.

3. **Автор - книги**
   Один автор может написать несколько книг. При этом каждая книга может быть связана с одним автором. Поэтому это связь **1:N**, а не 1:1.

4. **Дом - квартиры**
   В одном доме может находиться много квартир. Каждая квартира находится в одном конкретном доме. Поэтому это связь **1:N**, а не 1:1.

## 3. Связь многие ко многим (M:N)

1. **Студенты - учебные предметы**
   Один студент изучает несколько предметов, и один предмет изучают много студентов. Поэтому здесь связь **M:N**.

2. **Фильмы - актёры**
   В одном фильме может сниматься много актёров, а один актёр может сниматься во многих фильмах. Поэтому это **M:N**, а не 1:N.

3. **Игроки - команды**
   Один игрок может выступать за разные команды в разные периоды, а в одной команде играет много игроков. Поэтому связь **M:N**.

4. **Рецепты - продукты**
   В одном рецепте используется несколько продуктов, а один продукт может использоваться во множестве рецептов. Например, картофель может быть в разных рецептах. Поэтому это **M:N**.
