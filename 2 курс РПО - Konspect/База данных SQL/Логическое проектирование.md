#### Ограничения в SQL:

1. NULL / NOT NULL - гарантирует, что в атрибуте будет или не будет значения
2. UNIQUE - Обеспечивает уникальность значений в атрибуте или группе атрибутов
3. PRIMARY KEY (первичный ключ) - Однозначно идентифицирует каждую строку в сущности
4. FOREIGN KEY (внешний ключ) - Он гарантирует, что значения в атрибуте (или группе атрибутов) внешнего ключа в одной сущности соотвествуют существующим значениям в первичном ключе другой сущности. создает связь между двумя сущностями
5. CHECK - Служит для проверки значений по определенному условию.
6. DEFAULT - устанавливает значения по умолчанию
