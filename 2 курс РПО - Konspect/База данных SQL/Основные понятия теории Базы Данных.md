Данные - это информация представленная в определенном виде, может быть хаотична или в упорядоченном формате.

База данных - это совокупность данных, организованных по определенным правилам, предусматривающая хранение, описание, манипулирование и удаление данных. (ячейка, место где хранятся данные)

СУБД (Система Управления Базой Данных) - это целый комплекс программ, позволяющий создавать базу данных и манипулировать данными.

#### Самые популярные СУБД:
- Microsoft SQL Server (MS SQL Server)
- MYSQL
- Oracle
- PostgreSQL
- MongoDB

SQL (язык запросов) - это специализированный язык, предназначенный для работы БД.

#### Особенности SQL:
1. Не является самостоятельным ЯП.
2. Имеет четкую структуру, близок к естественному английскому языку.
3. Имеет декоративный характер - при написании кода пользователь указывает, что хочет получить а система сама определяет, как выполнить задачу.
4. В нем нет циклов, ветвей и других  привычных процедурных конструкций.

#### Список диалектов для языка SQL:
1. T-SQL (TransactSQL) - используется в Microsoft SQL Server
2. PL/SQL (Procedural Language/SQL) - используется в Oracle
3. SQL/PSM - используется в MySQL
4. PLpg/SQL - используется PostgreSQL
5. Jet SQL - используется в Microsoft Access

### Технологии работы БД
1. Централизованная архитектура (все находится на одном ПК). Один специалист на одном ПК закрывает эту потребность.
Преимущества:
* Очень легко управлять, все находится в одном месте
* Максимальная безопасность
Недостатки:
* Колоссальная нагрузка на компьютер
* Если сломается компьютер - будет нерабочая база данных

2. Архитектура файлов-сервера - участвуют персональные компьютеры и выделенные серверы, на котором хранится файлы. Сервер не участвует в разработке своих данных (Сохраняются только последние изменения). Если человек зашел в файл и изменил сначала в ней что-то, и в этот момент зашел другой человек в файл и они оба сохранили, то сохранится, кто последний нажал сохранить.
Преимущества:
* Дешево и просто сделать общий доступ
* Каждый использует свою мощность ПК для вычислений
Недостатки:
* Огромный трафик
* Конфликты одновременного использования

![[Pasted image 20260908131326.png]]

3. Архитектура клиент-сервер 
Преимущества:
* Малая нагрузка на сеть
* Масштабируемость
* Централизованное управление
* Повышенная безопасность
* Эффектная совместная работа
Недостатки:
* Зависимость от сервера
* Зависимость от сети
* Задержка из-за удаленного сервера

4. Архитектура трехуровневая (многоуровневая) - архитектура клиент-сервер - сервер баз данных, где хранятся информация о товарах, пользователях и заказах.
Преимущества:
* Гибкость изменения
* Масштабируемость
* Снижение требований к ПК клиента
* Повышенная отказоустойчивость
Недостатки:
* Очень сложная разработка
* Задержка ответа по сети
* Большие затраты на обслуживание

### Модели баз данных
Модель баз данных - это способ структурирования данных и описания взаимосвязей между ними.

1. Файловая модель - состоит из поля и файлов записи. Нет связи между файлами.
2. Иерархическая модель - появились связь (родитель потомок). Модель представляется в виде иерархии. 
3. Сетевая модель - представляет собой развитие иерархической модели. Модель позволяет описывать более сложные взаимосвязи. Появляется связь многое ко многим. 
4. Реляционная модель - самая популярная. Данные предоставляются в виде таблиц. В этой модели присутствуют связи один к одному, 1 к многому и много ко многому.
5. Гибридная модель - объектно-реляционной моделью

### Основные понятия реляционной модели

1. Сущность (таблица) - это представление набора, реальных или абстрактных объектов (люди, аудитории, животные, события, места), который имеет общие характеристики. 
2. Атрибут (подзаголовок столбца) - это именование характеристик. которая является частью сущности.
3. Кортеж (Одна строка) - это каждая строка сущности, которые хранятся данные разных типов.
4. Связь - взаимосвязь между двумя сущностями.

### Виды связей:
* Один к одному (один - один) - одна запись из главной таблицы соответствует только одной записи из другой таблицы
* Отношение 1 к многому (один - к-n) - самая часто используемая связь, одна запись из главной таблицы соответствует нулю, одной или нескольким записям второй таблицы. 
  1 - 1 = -
  1 - N = на несколько
* Многое ко многому (n-k-n) - часто используемая, но самая сложная связь одна или много записей из главной таблицы могут соответствовать записям из другой таблицы.

Первичный ключ (уникальный) - это уникальное поле, которое идентифицирует каждый кортеж сущности.
Вторичный ключ (внешний) - столбец или набор столбцов, в одной таблице, которая ссылается на первичный ключ главной таблицы.

Есть обязательные и необязательные связи
Необязательные (пишется кружочком)
Обязательно (пишется | - горизонтальной палочкой )
