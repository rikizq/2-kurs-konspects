Цикл - набор действий, который выполняется пока истинно определенное условие (условие цикла).
  
Счетчик/промежуточный элемент/индексом - локальная переменная, которая работает внутри цикла.  
  
Итерация - набор команд тела цикла (линейные команды, условия, циклы)  
  
while() - цикл с пред. условием. Сначала думает, потом делает. ЦИКЛ МОЖЕТ НИ РАЗУ НЕ ВЫПОЛНИТЬСЯ.  
  
do while() - цикл с пост условием. Сначала делает, потом думает (правило дурака). ЦИКЛ, КАК МИНИМУМ, СДЕЛАЕТ ОДНУ ИТЕРАЦИЮ.  
  
Принцип цикла заключается в повторении итерации и дальнейшей проверке условия. Если после определения итерации условие становится False, то происходит выход из цикла (завершение цикла).  
  
Для удобства взаимодействия с сложными типами данных, был разработан цикл for, который определяет внутри себя локальную переменную - индекс, условие, и его инкремент. for РАБОТАЕТ КОГДА МЫ ЗНАЕМ ТОЧНОЕ КОЛИЧЕСТВО ПОВТОРЕНИЙ. for является циклом пред условия.  
  
foreach - позволяет удобно работать с объектами.

При работе с циклом while, вы должны составить действие, при котором вы выйдите из цикла. Если условие в сравнений значений - стремитесь к данному исключению. Если используется константное True в теле цикла, составить условие для break.

break - принудительное завершение всего цикла.
continue - принудительное продолжение всего цикла.
