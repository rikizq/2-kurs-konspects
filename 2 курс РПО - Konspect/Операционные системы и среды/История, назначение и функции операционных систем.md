## 1. Что такое операционная система

Операционная система (ОС) - это комплекс взаимосвязанных программ, который управляет аппаратными ресурсами компьютера (процессором, памятью, устройствами ввода-вывода) и предоставляет пользователю удобный интерфейс для работы с устройством и прикладными программами.

**Два режима работы компьютера:**

- Режим ядра (супервизора) - полный доступ к оборудованию, любые инструкции;
- Режим пользователя - доступно лишь подмножество инструкций; запрещены команды управления машиной и операции ввода-вывода (I/O).

**Место ОС в структуре ПО** :

![[Pasted image 20261019153804.png]]

- внизу - аппаратное обеспечение (микросхемы, платы, диски, клавиатура, монитор);
- над ним - программное обеспечение;
- ОС работает непосредственно с аппаратурой и служит основой остального ПО;
- выше - оболочка/GUI (пользовательский интерфейс), прикладные программы (браузер, почта, плеер).

Важное отличие ОС от пользовательских программ: пользователь может заменить программу почты, но не может написать собственный обработчик прерываний системных часов - он защищён на аппаратном уровне. Программы, работающие в режиме ядра, безусловно являются частью ОС; некоторые программы в режиме пользователя (например, смена паролей) также тесно связаны с ОС.

Масштаб: исходный код ОС типа Linux или Windows - порядка **5 млн строк** (≈100 томов по 1000 страниц); Windows с библиотеками - до **70 млн строк** (10–20 книжных полок). Поэтому ОС создаются очень трудно и живут долго, развиваясь десятилетиями:

- семейство Windows 95/98/Me - одна ОС;
- семейство Windows NT/2000/XP/Vista/7 - другая (при схожем интерфейсе);
- UNIX и клоны: System V, Solaris, FreeBSD; Linux - новая программная основа при близкой к UNIX модели и высокой совместимости.

## 2. Две функции ОС (два взгляда)

### 2.1. ОС как расширенная машина (взгляд сверху вниз)

Аппаратура на машинном языке слишком примитивна и неудобна. Пример: описание интерфейса дисков SATA в книге 2007 г. занимало **свыше 450 страниц** и с тех пор усложнилось.

ОС скрывает сложность через абстракции:

- драйвер диска - интерфейс чтения/записи блоков без деталей оборудования;
- файл - абстракция для работы с диском (фотография, письмо, веб-страница);
- абстракция превращает неподъёмную задачу в две решаемые: (1) определение и реализация абстракций, (2) их использование.


Ключевая идея: ОС превращает «уродливое» аппаратное обеспечение в красивые, элегантные, неизменные абстракции

![[{9D59E165-378A-4ED7-B645-43FEDBAF8B87}.png]]

«Заказчики» ОС - прикладные программы; конечные пользователи работают с абстракциями пользовательского интерфейса (командная строка, GUI), которые могут отличаться от абстракций ОС (пример: мышиный рабочий стол Windows vs командная строка; Gnome/KDE vs X Window System в Linux - абстракции ОС одни и те же).

### 2.2. ОС как менеджер ресурсов (взгляд снизу вверх)

ОС управляет процессорами, памятью, таймерами, дисками, мышами, сетевыми интерфейсами, принтерами. Задачи:

- упорядоченное распределение ресурсов между программами;
- отслеживание, какая программа какой ресурс использует;
- удовлетворение запросов, учёт использования, разрешение конфликтов.


Пример: три программы печатают одновременно на один принтер → без ОС получится «каша». ОС буферизует вывод на диск и после завершения программы копирует его на принтер.

Мультиплексирование ресурсов - два способа:

- во времени - по очереди (ЦП выделяется одной программе, затем другой; очередь заданий на печать);

- в пространстве - каждый клиент получает часть ресурса (оперативная память делится между программами; диск - файлы разных пользователей). Возникают проблемы равного доступа, безопасности - их решает ОС.


### 3. История развития операционных систем

Развитие операционных систем связано с совершенствованием компьютеров и необходимостью более эффективного использования вычислительных ресурсов.

Первое поколение (1945–1955 годы). Компьютеры строились на электронных лампах. Современных операционных систем не было, программы запускались вручную, а управление компьютером осуществлялось операторами.

Второе поколение (1955–1965 годы). С появлением транзисторов компьютеры стали надёжнее. Возникли системы пакетной обработки, которые позволяли объединять задания в группы и выполнять их последовательно без постоянного участия оператора.

Третье поколение (1965–1980 годы). Распространение интегральных схем способствовало развитию более сложных ОС. Появились многозадачность и системы разделения времени, позволяющие эффективнее распределять ресурсы между заданиями и пользователями.

Четвёртое поколение (с 1980-х годов). Началось массовое распространение персональных компьютеров. Развивались графические интерфейсы, сетевые возможности и средства защиты информации. Позднее появились мобильные ОС для смартфонов и планшетов.

### 4. Основные функции операционной системы

ОС выполняет следующие функции:

1. Управление процессами - запуск, выполнение и завершение программ, распределение процессорного времени.
2. Управление памятью - распределение оперативной памяти между программами и контроль её использования.
3. Управление файлами - создание, хранение, чтение, запись, копирование и удаление файлов.
4. Управление устройствами - организация работы клавиатуры, мыши, монитора, принтера и накопителей.
5. Обеспечение пользовательского интерфейса - предоставление средств взаимодействия пользователя с компьютером.
6. Защита информации - разграничение доступа к ресурсам и защита данных.
7. Управление ресурсами - эффективное распределение ресурсов компьютера между выполняемыми задачами.

Важной функцией ОС является многозадачность. Она позволяет организовать выполнение нескольких программ, распределяя между ними процессорное время и другие ресурсы.

## 5. Обзор аппаратного обеспечения компьютера

Простая модель ПК: центральный процессор, память и устройства ввода-вывода соединены системной шиной. Современные ПК сложнее и используют несколько шин.

![[{4572F3FD-01DA-468F-B57D-F667C006DC98}.png]]

Центральный процессор (ЦП) - «мозг» компьютера. Цикл: выборка команды из памяти → декодирование (тип и операнды) → выполнение → повтор.

- Набор команд специфичен для архитектуры: x86 не выполняет программы ARM и наоборот.

- Доступ к памяти медленнее выполнения команды, поэтому у ЦП есть **регистры** для переменных и промежуточных результатов; команды загрузки слова из памяти в регистр и запоминания из регистра в память; команды над операндами из регистров/памяти.

- **Специальные регистры:**

- **счётчик команд** - адрес следующей выбираемой команды (обновляется после выборки);
- **указатель стека** - вершина стека; стек хранит по фрейму на каждую процедуру (входные параметры, локальные и временные переменные);
- **слово состояния программы (PSW)** - биты кода условия, приоритет ЦП, режим (пользовательский/ядра) и служебные биты. Пользовательские программы могут читать PSW целиком, но записывать - только некоторые поля. PSW играет важную роль в системных вызовах и операциях ввода-вывода.
- ОС должна знать состояние всех регистров; при временном мультиплексировании ЦП она часто переключает процессы.
### 6. Значение операционных систем

Операционные системы являются основой программного обеспечения современных компьютеров. Они позволяют запускать приложения, управлять файлами и устройствами, распределять ресурсы и обеспечивать безопасность данных.

Без операционной системы разработчикам пришлось бы самостоятельно учитывать множество особенностей аппаратного обеспечения. ОС упрощает эту работу, предоставляя программам стандартные механизмы взаимодействия с компьютером.

Операционные системы отличаются сложной структурой и длительным сроком использования. Их развитие происходит постепенно, поскольку создание и проверка новой системы требуют значительных усилий.
