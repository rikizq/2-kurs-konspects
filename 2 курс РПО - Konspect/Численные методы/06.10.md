Первое условие: f(a) * f(b) < 0.  
Второе условие: f(x) на [a, b].

Берём область определения функции или нужный интервал и делим его на мелкие части с шагом h. Шаг выбирается автоматически по формуле: h = (B - A) / N, где N — количество частей, на которые разбили интервал. Тогда x(i) = A + ih.

Если f(x) > 0 и функция монотонно возрастает — корень один.  
Если f(x) < 0 и функция монотонно возрастает — корень также один.

Если функция меняет знак, корней может быть несколько.

m(1) = min |f(x)| при x, принадлежащем [a, b].

Сходимость итерационного метода:

x(k+1) = φ(x(k)).

Свойство последовательности приближаться к истинному корню, то есть предел при k → ∞ равен X.

Условие сходимости: есть понятие коэффициента сжатия (q). Он всегда берётся по абсолютной величине и показывает, во сколько раз уменьшается погрешность за одну итерацию: q = φ(x).

Линейная сходимость — каждая итерация добавляет примерно одинаковое количество верных знаков.  
Квадратичная сходимость — количество верных знаков удваивается с каждой итерацией.

Невязка — это значение функции в приближении к корню, f(x*). Она показывает, насколько хорошо приближённый корень удовлетворяет уравнению. Если f(x*) = 0, то x* — точный корень x.

| x(k+1) - x(k) | < E.

Оценка погрешности.

f(x*) - f(x) = f(c) (x* - x), так как f(x) = 0, то f(x*) приближённо равно f(c) (x* - x).

Для функции, непрерывной на отрезке и дифференцируемой на интервале, существует точка, в которой производная равна среднему значению приращения функции.

| x* - x | = | f(x*) / m(1) |, где m(1) = min при x, принадлежащем [a, b], — гарантированная верхняя оценка.

СЛАУ (система линейных алгебраических уравнений) — совокупность n уравнений с n неизвестными, в которой каждая переменная входит только в первой степени и отсутствуют произведения переменных.

Правило умножения матрицы на вектор.

Элемент i-й строки результата равен скалярному произведению i-й строки матрицы A на вектор x.

Расширенная матрица — это краткая запись системы линейных алгебраических уравнений (СЛАУ), которая состоит из коэффициентов при неизвестных и добавленного справа столбца свободных членов.

Три исхода:

- система имеет единственное решение;

- система имеет бесконечно много решений;

- система вообще не имеет решений.


Определитель (детерминант) квадратной матрицы — это числовая величина, которая вычисляется по элементам матрицы и характеризует её свойства.

Главное в методе Гаусса — это последовательное исключение неизвестных.

Треугольная система в методе Гаусса — это вид системы линейных алгебраических уравнений , в которой матрица коэффициентов приведена к треугольному виду, где все элементы ниже главной диагонали равны нулю.

Треугольная система — это система, где первое уравнение содержит все неизвестные, второе — все, кроме x1, а третье — только x3.

Обратный ход — это когда мы идём снизу вверх и последовательно вычисляем, начиная с x3.
