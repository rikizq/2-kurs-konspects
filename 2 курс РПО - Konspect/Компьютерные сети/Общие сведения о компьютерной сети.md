Компьютерная сеть - это система, объединяющая компьютеры и другие устройства (серверы, принтеры, маршрутизаторы) для обмена данными и ресурсами.

Цель - удаленный доступ к разделяемым ресурсам (пользователи могут по сети получить данные с другого компьютера на расстоянии.

### Классификация компьютерных сетей
- По среде передачи данных (проводные и беспроводные)
- По скорости передачи данных (низкоскоростные, среднескоростные, высокоскоростные)
- По размеру охваченной территории (глобальные, региональные, локальные)
- По организации локальной сети (одноранговые и с выделенным сервером)

### Сетевые характеристики
Трафик - объем передаваемых по сети данных. Различают входящий трафик данных, получаемых компьютером из сети, и исходящий трафик данных, отправляемых компьютером в сеть. Измеряется в байтах.

Скорость передачи данных - это фактическая скорость потока данных, прошедшего через сеть. Определяется как отношение объема переданных данных за промежуток времени на продолжительность этого промежутка. Базовая единица - бит/сек.

1 кбит/c = 1000 бит/с
1 Мбит/с = 1000 кбит/c
1 Гбит/с = 1000 Mбит/с
1 Тбит/с = 1000 Гбит/с

Пропускная способность - максимально возможная скорость передачи данных по каналу связи. Зависит от качества и характеристики физической среды передачи данных и используемой технологии передачи данных.

### Топология сети
Топология сети - схема расположения и соединения сетевых устройств. От неё зависят характеристики сети: например, несколько путей между узлами повышают надёжность и позволяют распределять нагрузку по каналам.

### Виды топологий
Различают следующие топологии компьютерных сетей:
- полносвязную
- ячеистую
- кольцевую
- звездообразную («звезда»)
- древовидную
- общую шину
- смешанную

1. Полносвязная
Как устроена: Каждый компьютер соединён с каждым отдельным кабелем.
Плюсы: Максимальная надёжность, высокая скорость, обрыв одного канала не ломает сеть.
Минусы: Очень дорого и сложно, много кабеля.
![[Pasted image 20260923152200.png]]

2. Ячеистая
Как устроена: Много соединений по определённой схеме, у данных несколько маршрутов.
Плюсы: Высокая надёжность, устойчивость к обрывам, гибкость.
Минусы: Сложная настройка.
![[Pasted image 20260923152210.png]]

3. Кольцевая
Как устроена: Устройства соединены последовательно в замкнутое кольцо, данные идут по цепочке.
Плюсы: Нет коллизий, предсказуемая скорость, простая логика.
Минусы: Обрыв одного узла может разорвать все кольцо, сложно добавлять устройства.
![[Pasted image 20260923152219.png]]

4. Звездообразная («звезда»)
Как устроена: Все подключены к одному центральному устройству отдельными кабелями.
Плюсы: Легко добавлять устройства, просто искать неисправности, поломка кабеля не влияет на остальных.
Минусы: Выход из строя центра - встанет вся сеть, больше кабеля.
![[Pasted image 20260923152233.png]]

5. Древовидная
Как устроена: Иерархия из нескольких «звёзд», соединённых через верхние узлы.
Плюсы: Хорошо масштабируется, подходит для крупных сетей.
Минусы: Отказ верхнего уровня рушит ветку, сложнее настройка.
![[Pasted image 20260923152245.png]]

6. Общая шина
Как устроена: Все подключены к одному общему кабелю.
Плюсы: Простота, дешевизна, минимум кабеля.
Минусы: Обрыв кабеля рушит всю сеть, возможны коллизии, падает скорость при нагрузке.
![[Pasted image 20260923152253.png]]

7. Смешанная
Как устроена: Комбинация разных топологий на разных участках сети.
Плюсы: Гибкость, сочетает достоинства разных топологий.
Минусы: Сложнее проектировать и обслуживать.
![[Pasted image 20260923152307.png]]
